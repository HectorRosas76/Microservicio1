Aplicacion de Alquiler de Vehiculos

Registra vehiculos, clientes, reservas, la disponibilidad, historial y devoluciones

Para activar los servicios
Clientes - php -S 127.0.0.1:8081 -t public (PUERTO)
Reservas - php -S 127.0.0.1:8071 -t public (PUERTO)
Vehiculos - php -S 127.0.0.1:8061 -t public (PUERTO)

Para funcionar, subir localmente la basedata de los micro servicio (copia directamente los sql de microservicios a phpmyadmin en el apartado SQL)
